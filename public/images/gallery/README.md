# Gallery photos

Drop your real shop photos here, named:

```
work-1.jpg   work-2.jpg   work-3.jpg
work-4.jpg   work-5.jpg   work-6.jpg
```

(or `.png` / `.webp` — but then update the file names in `public/index.html`).

Suggested content (one per slot):
1. Before/after collision repair — wide shot
2. Paint booth or color-matching work
3. Bumper repair close-up
4. Shop interior / bay area
5. Team or owner at work
6. Finished, polished car ready for pickup

**Tips for Google Ads landing photos:**
- Aspect ratio: 4:3 or 3:2 works best with the grid
- File size: keep under 300 KB each (compress with squoosh.app or tinypng.com)
- Resolution: 1200×900 is plenty — the grid renders at ~600px wide
- Lighting: bright, clean shots build the most trust

The bundled `.svg` files in this folder are placeholders. Once you drop a `.jpg` with the matching number in, update the `src` path in `index.html` (search for `/images/gallery/work-`).
